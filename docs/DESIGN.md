# Muni design

Source of truth: `.cursor/skills/capstone-muni-design/SKILL.md` plus the shared
Capstones harness in `capstone-signal-design`.

## Product

**Muni** is a grounded personal AI mascot and brand. Pitch:

> Meet Muni. The personal AI that only speaks from verified knowledge.

Muni comes from Filipino "muni-muni" (thoughtful reflection).

## Tokens

- Canvas `#F2F3F7`, Surface `#FFFFFF`, Ink `#101828`, Muted `#667085`
- Primary `#D97706`, Bright `#F59E0B`, Fog `#FEF3C7`
- Fonts: Outfit + Figtree + IBM Plex Mono

## Required hooks

- Interactive mascot states: idle, wave, listening, thinking, answering, grounded-refuse
- Grounding strip under CTAs
- Citation / knowledge marquee
- Grounding Guard chapter
- Chat UI + owner inbox desk
